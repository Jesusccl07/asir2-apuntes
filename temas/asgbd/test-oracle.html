Procesos de Oracle

El PDF distingue tres tipos. Los nombres de los procesos background salen en el ps -eaf del PDF y en tu Docker (db_pmon_FREE, db_lgwr_FREE…); lo que hace cada uno es ampliación.

Tablespaces que crea Oracle al instalar

Antes de meter datos hay que crear el espacio donde irán las tablas: el tablespace. Cada uno tiene uno o varios ficheros de datos.

Estructura lógica y física

Toca cada nivel o pulsa «Animar» para recorrerlo de arriba abajo.

Las flechas rosas son los dos enlaces entre lo lógico y lo físico: tablespace ↔ fichero de datos y bloque Oracle ↔ bloques del S.O.

Un fichero, un solo tablespace

Un tablespace puede tener varios ficheros, pero un fichero no se comparte entre dos tablespaces (la ✗ del PDF).

Esquema y diccionario de datos

Esquema = usuario: sus objetos (tablas, índices, sinónimos, vistas). El diccionario de datos es la «información de la información».

USER_

Solo lo del propio usuario

ALL_

Todo lo que el usuario puede ver

DBA_

Todo lo de la BBDD (administrador)

V$

Vistas dinámicas del estado de la instancia
